# betterinput

Minecraft 1.21.11 Fabric rich input tools for books and signs.

## Features

- Adds formatting buttons to the book writing screen.
- Adds formatting buttons to the sign editing screen.
- Supports colors, bold, italic, underline, strikethrough, obfuscated, and reset.
- Books can attach a click-to-run command link to selected text before signing.

Book links require this mod on both client and server.
